### `src/lib/sync/despesa-id.ts` (utility, transform — key derivation)

**Analog:** `src/lib/sync/camara-adapter.ts` — `hashString` + `makeDiscursoIdExterno` (lines 131-144)

**Import pattern** (adapter lines 1-7 — note bare `crypto`, no path alias needed here):
```typescript
import { createHash } from 'crypto';
```

**Core pattern — deterministic content-derived key with hash** (lines 131-144):
```typescript
function hashString(input: string): string {
  return createHash('md5').update(input).digest('hex').slice(0, 12);
}

// A API de discursos por deputado não expõe um id único. Montamos uma chave
// determinística a partir dos campos disponíveis para permitir upsert idempotente.
function makeDiscursoIdExterno(deputadoIdExterno: string, d: CamaraDiscurso): string {
  const base = [
    d.dataHoraInicio || '',
    d.tipoDiscurso || '',
    d.urlTexto || '',
    (d.sumario || '').slice(0, 200),
  ].join('|');
  return `CAMARA-${deputadoIdExterno}-${hashString(base)}`;
}
```

**Adaptation for Despesa (RESEARCH Pattern 1, S6):** same idea, but **sha256[:16] not md5[:12]** (P8: md5[:12] is fine for discursos' low volume; the despesa gate proved sha256[:8] collides 4× at 209k rows — `slice(0, 16)` is the researched floor):
```typescript
import { createHash } from 'node:crypto';

export function derivarIdExternoDespesa(casa: 'CAMARA' | 'SENADO', raw: Record<string, unknown>): string {
  if (casa === 'SENADO') return `SENADO:${String(raw.id)}`;
  const fp = createHash('sha256').update(JSON.stringify(raw)).digest('hex').slice(0, 16);
  return `CAMARA:${String(raw.idDocumento)}:${fp}`;
}
```

**Module conventions to copy:** kebab-case filename (`despesa-id.ts`), named export only (no default), module-level block comment stating purpose, pure function taking plain data (no Prisma/Request), `crypto` from stdlib — never hand-roll a hash (RESEARCH "Don't Hand-Roll").
